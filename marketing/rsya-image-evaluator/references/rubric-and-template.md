# Шкала оценки и шаблон отчёта для РСЯ / ЕПК

## Дескрипторы 7 критериев (шкала 1–10)

### 1. Смарт-обрезка и геометрия (вес 1.5)
- **9–10**: Главный объект строго в безопасной центральной зоне с достаточным запасом фона. На всех кропах (`1:1`, `3:4`, `16:9`) композиция выглядит сбалансированно, ничего важного не отрезано.
- **7–8**: Объект сохраняется целиком, но в одном из крайних кропов (`16:9` или `3:4`) границы проходят вплотную к краю — потребуется ручная настройка смарт-центра в интерфейсе Директа.
- **5–6**: В одном из форматов отсекается второстепенная, но заметная часть сцены; картинку можно использовать только в своей родной пропорции, не как универсальную.
- **1–4**: При обрезке режутся лицо, продукт или текст. Непригодно для адаптивных блоков ЕПК.

### 2. Читаемость в мелком тизере 120×90 px (вес 1.5)
- **9–10**: Сюжет и предмет рекламы считываются мгновенно даже в миниатюре. Один крупный объект, чёткий силуэт, высокий контраст с фоном.
- **7–8**: Объект узнаваем, но на фоне есть пара лишних деталей, слегка снижающих контраст.
- **5–6**: В миниатюре картинка превращается в «кашу» — нужно присматриваться, чтобы понять, что изображено.
- **1–4**: Полная потеря читаемости: слишком много мелких объектов, общий план издалека, низкий контраст.

### 3. Стоп-эффект / анти-баннерная слепота (вес 1.3)
- **9–10**: Цепляет взгляд за счёт сильного цветового акцента, нестандартного ракурса, живой эмоции или выразительного контраста. Не похоже на шаблонный баннер.
- **7–8**: Заметный, опрятный визуал, выделяется на белом/светлом фоне сайтов.
- **5–6**: Нейтральная, предсказуемая картинка — часть аудитории пролистает не заметив.
- **1–4**: Блёклое, сливающееся с фоном или клишированное стоковое фото, которое мозг фильтрует автоматически.

### 4. Ясность оффера без текста (вес 1.2)
- **9–10**: Даже без заголовка объявления понятно, какая услуга/товар и для кого показаны (или какой результат получает клиент).
- **7–8**: Ниша считывается сразу, точный оффер раскрывается в связке с заголовком ЕПК.
- **5–6**: Слишком абстрактная метафора — без текста вообще непонятно, что рекламируется.
- **1–4**: Картинка не связана с продуктом или вводит пользователя в заблуждение.

### 5. Реализм и качество исполнения (вес 1.1)
- **9–10**: Естественный свет, чистая резкость, убедительные текстуры, ноль ИИ-артефактов. Выглядит как профессиональная живая съёмка или аккуратная фирменная графика.
- **7–8**: Хорошее качество, мелкие шероховатости не бросаются в глаза на обычном экране.
- **5–6**: Заметен «нейросетевой глянец», неестественная кожа/свет, лёгкое мыло или стоковая наигранность.
- **1–4**: Явные дефекты генерации, низкое разрешение, сильный шум, артефакты сжатия.

### 6. Чистота от текста и визуального шума (вес 1.0)
- **9–10**: Текста на картинке нет вообще (0%) — всю текстовую нагрузку несут заголовки и тексты ЕПК. Фон чистый.
- **7–8**: Есть минимальный крупный акцент или логотип (< 10–15% площади), который не обрезается и читается в миниатюре.
- **5–6**: Текст занимает 15–20% площади или шрифт мелковат для мобильных блоков.
- **1–4**: Перегруженный текстом баннер (> 20%), мелкий нечитаемый шрифт, плашки по краям, которые режутся смарт-обрезкой.

### 7. Доверие и бренд-контекст (вес 0.9)
- **9–10**: Вызывает спокойное профессиональное доверие, точно попадает в ожидания целевой аудитории и визуальный тон бренда.
- **7–8**: Адекватно нише, без отталкивающих элементов.
- **5–6**: Чуть слишком «агрессивно-рекламно» или мимо визуального кода аудитории.
- **1–4**: Дешевит бренд, выглядит подозрительно или неуместно для тематики (особенно критично для медицины и B2B).

## Шаблон итогового отчёта

```markdown
## Оценка изображения для РСЯ / ЕПК: `<имя_файла>`

**Вердикт:** [В запуск / В запуск с правками / Доработать до запуска / Переделать с нуля]
**Итоговый балл:** X.X / 10
**Техпроверка ЕПК:** [OK / Ошибки — размер, пропорция, тип REGULAR/WIDE]
**Стоп-фильтр модерации:** [Пройден / Есть риски — указать конкретно]

### Оценка по критериям

| Критерий | Балл | Вес | Комментарий |
|---|---:|---:|---|
| 1. Смарт-обрезка и геометрия | /10 | 1.5 | |
| 2. Читаемость в тизере (120×90) | /10 | 1.5 | |
| 3. Стоп-эффект (анти-слепота) | /10 | 1.3 | |
| 4. Ясность оффера без текста | /10 | 1.2 | |
| 5. Реализм и качество | /10 | 1.1 | |
| 6. Чистота от текста и шума | /10 | 1.0 | |
| 7. Доверие и бренд-контекст | /10 | 0.9 | |

### Взгляд с трёх сторон
- **Контекстолог (РСЯ/ЕПК):** ...
- **Модератор Директа:** ...
- **Пользователь на площадке:** ...

### Приоритетные правки (Топ-3)
1. ...
2. ...
3. ...

### Рекомендация по использованию в ЕПК
- Под какие пропорции загружать (`1:1`, `3:4`/`4:3`, `16:9`) и нужно ли смещать смарт-центр.
- Нужно ли перегенерировать через `rsya-image-prompt` (и что именно изменить в промпте).
```
