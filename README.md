# komdev-skills

Коллекция агентских скиллов (`SKILL.md`) для ИИ-ассистентов (Antigravity, Claude Code, Cursor, Codex и других агентов, поддерживающих стандарт Agent Skills).

---

## Маркетинг (`marketing/`)

Набор скиллов для подготовки, генерации и QA-проверки рекламных изображений под **РСЯ и Единую перфоманс-кампанию (ЕПК) Яндекс Директа**.

### 1. [`rsya-image-evaluator`](marketing/rsya-image-evaluator/SKILL.md) — оценка готовых изображений для РСЯ / ЕПК
Экспертный QA-аудит рекламных креативов перед загрузкой в комбинаторные объявления (`RESPONSIVE_AD`).

**Что делает:**
* **Инструментальная техпроверка** ([`scripts/check_rsya_image.py`](marketing/rsya-image-evaluator/scripts/check_rsya_image.py)): проверяет формат (`JPG`/`PNG`/`GIF`), вес (≤ 10 МБ), минимальные и максимальные разрешения `REGULAR` / `WIDE` и отлавливает частую ошибку нейросетей — **«почти 16:9»** (например, `1376×768`), которую Директ отклоняет как широкоформатную.
* **Контрольный лист кропов и тизера**: автоматически собирает превью-лист с центральной безопасной зоной, кропами `1:1`, `3:4`, `16:9` и имитацией мелких тизерных блоков РСЯ (`120×90 px` и `80×80 px`).
* **Стоп-фильтр модерации Яндекс Директа**: проверяет риски по ФЗ-38, запрет иностранной латиницы без русского аналога (с 01.03.2026), запрет коллажей «до/после» и шок-контента в медицине, фейк-интерфейсов и явных ИИ-артефактов.
* **Оценка с 3 позиций и скоринг 1–10**: разбор глазами специалиста по контексту, модератора и пользователя + взвешенный балл по 7 критериям с вердиктом (*В запуск / Доработать / Переделать*).

**Зависимости для скрипта:** Python 3 и `Pillow` (`pip install pillow`).

### 2. [`rsya-image-prompt`](marketing/rsya-image-prompt/SKILL.md) — оценка, правка и написание промптов для рекламы
Помогает писать и исправлять промпты для генерации статичных рекламных изображений под РСЯ / ЕПК в **Gemini / Nano Banana, Flux, GPT Image, Midjourney, Ideogram и Recraft**.

**Что делает:**
* **Архитектура «4 опоры РСЯ-промпта»**: один главный фокусный объект, центрированная композиция с запасом фона под смарт-обрезку `1:1` / `3:4` / `16:9`, контраст против баннерной слепоты и позитивные ограничения без сгенерированного текста и логотипов.
* **4 фильтра проверки промпта перед генерацией**: структура → профилактика ИИ-артефактов (руки, зубы, лишний текст) → совместимость с РСЯ и модерацией Директа → адаптация синтаксиса под конкретную модель.
* **Шпаргалка по моделям и сценам** ([`references/model-guide.md`](marketing/rsya-image-prompt/references/model-guide.md)): готовые паттерны для предметки, услуг/медицины, нативных сцен и интерьеров + таблица быстрых правок типовых дефектов.

## Как скиллы работают вместе

1. **`rsya-image-prompt`** — составляете или проверяете промпты перед генерацией, чтобы сразу заложить безопасную зону под кроп, контраст и чистоту от текста.
2. **Генерация** — получаете изображения в нужном генераторе.
3. **`rsya-image-evaluator`** — прогоняете готовые файлы через скрипт техпроверки и визуальный аудит кропов/модерации перед загрузкой в Директ. Если выявлены дефекты — возвращаетесь в `rsya-image-prompt` с точечным списком правок.

## Установка

### Через CLI (`skills.sh`)
```bash
npx skills add fr00st/komdev-skills
```

### Вручную
Скопируйте нужную папку из `marketing/` в директорию скиллов вашего проекта или глобальную папку агента:
* `.agents/skills/` (Antigravity и совместимые агенты)
* `.claude/skills/` (Claude Code)
